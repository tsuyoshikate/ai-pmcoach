# 可选 AI 诊断接入

GitHub 与公开网站版本默认不调用大模型，下载后可以直接运行现有规则诊断。不包含作者的本地 GPT 适配器、账号凭据或代理配置。

指令全文见 [AI_DIAGNOSIS_PROMPT.md](AI_DIAGNOSIS_PROMPT.md)，代码常量在 `src/ai-diagnosis.js`。输入包含维度名、估计分及该维度全部题号、考核点、难度、对错、选项和解析。模型输出必须是五段中文自然语言，禁止 JSON 和代码。内部接口运输可以使用 JSON 包装文本，前端安全地按段落显示。

如需接入，自行实现同源后端并开启 `VITE_LOCAL_AI=1`。需要两个接口：

- `GET /api/ai-status` 返回 `{available:true, token:临时会话随机值}`。
- `POST /api/diagnose` 接收 `{state, dimensionId}`，前端携带 `X-AI-Session`。后端核验 Origin、会话值和完整答题记录，从可信题库重建维度输入，用 `buildDiagnosisPrompt` 构造指令，调用自己的模型后返回 `{text:五段中文报告}`。

不要信任前端提交的分数、解析或任意 prompt；请复用 `calculateResult` 验证答案并计算。密钥只放在后端。限制请求体、并发和超时时间，不开放任意模型指令执行接口。

前端 `generateDiagnosis` 最多尝试3次，第一次失败等1000ms、第二次失败等3000ms，第三次失败显示通用诊断。网络错误、HTTP错误、空文本、格式不符、虚构题号、鼓励引用错题、总结超30字符等均进入同一重试流程。用户退出页面会取消任务，不生成伪成功结果。

24段通用文本在 `src/diagnosis-fallbacks.js`：六个维度各4段。为避免边界重复，分档定义为 `[0,40)`、`[40,60)`、`[60,80)`、`[80,100]`；40、60、80均进入后一档。降级报告明确标注为通用内容，不冒充个人诊断。

生成成功或降级后的结果均保存在当前浏览器，绑定测评session及答案；刷新不重复消耗模型调用。点击生成按钮可重新生成。答题与能力计分始终由代码完成，不交给模型。

测试：`node --test tests/*.test.js`。
