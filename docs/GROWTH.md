# 复测与成长记录

完成18题CAT且实际选择答案至少10题时，保存能力快照；跳过不算有效作答。快照包含sessionId、完成时间/ISO日期、六维度得分、能力估计总分、题目数、实际作答数、答对数和正确率。正确率仍为主要成绩；雷达图与分数对比采用原CAT估计，总分与原结果页计算一致。

快照用ai-pmcoach-snapshots-v1保存，按完成时间排序，按sessionId去重。刷新或重复进入结果页不增加一条。主页会从已有且有效的完整CAT记录补建快照。早期15题版本的答题历史保持保存，但由于评分口径不同，不混入CAT快照对比。存储受限时不影响继续答题，原页面保留存储提示。

没有快照时保留原落地页，无新增登录系统；已有快照时首页自动显示成长主页：
- 1次：当前雷达图和复测提示。
- 2次起：最近两次叠加，本次主色实线及半透明填充，上次浅灰虚线且不填充。
- 对比能力估计总分、提升最大维度和退步/持平维度；无提升时如实说明，不虚构进步。
- 3次起提供完整成长曲线。#/growth展示时间轴与六条可切换的趋势线，按测评时间排列。

复测入口一直可点击。少于3天弱化；3—7天正常，未指定的8—14天也正常；超过14天高亮。提示天数按完整24小时向下取整。主页的诊断入口打开最近一次完整记录，即使另一个复测尚未完成，也不覆盖当前答题进度。

## 历史避题

ai-pmcoach-seen-questions-v1记录已提交过的题号，包括跳过题（用户也可能已在结果页看到答案）。已有历史和未完成测评的提交记录会合并，中途放弃的题也会保留。

新测评把历史题号冻结在previouslySeenIds中，刷新时验证和抽题都使用该份记录，避免新历史改变正在进行的题序。每个维度先筛选未见新题，再在新题中挑最接近当前难度的档位；没有新题时才回用旧题。同轮始终不重复、每个维度至少3题，按实际抽到的难度更新分数。控制台额外输出历史避题及旧题回用原因。

兼容以前没有previouslySeenIds字段的v4记录，既有分数与答案不变。所有快照、抽题、分数变化和对比计算由代码执行，不调用模型。
